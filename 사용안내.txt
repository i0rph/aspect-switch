Aspect Switch 1.0.0

호환되는 DDC/CI 모니터의 입력별 화면 비율을 자동으로 적용하는 독립 Windows 트레이 앱입니다.

1. AspectSwitch.exe를 실행합니다.
2. 모니터 호환성 → 모니터 검색 → 선택한 모니터 사용을 누릅니다.
3. 기기와 화면 → 기기 추가에서 이름, 입력, 화면 비율을 설정합니다.
4. 변경 사항 저장을 누릅니다.

기기를 여러 개 추가할 수 있고 입력당 하나씩 등록합니다.
카드 상단에서 기기 이름을 선택하거나 직접 입력을 선택해 원하는 이름을 적습니다. 사용 스위치와 삭제 버튼도 제공합니다.
트레이 더블클릭으로 설정을 엽니다. 우클릭 → 기기로 전환에서 수동 전환도 가능합니다.

AGP346UCSD는 화면 비율 프리셋이 있습니다.
다른 모델은 OSD에서 원하는 비율을 선택한 다음 모니터 호환성의
'OSD에서 선택한 비율 등록'에 이름을 입력해 현재 값을 등록하세요.
설정 창이 열린 동안 자동 적용은 잠시 멈춥니다.

브랜드 제한 없이 검색하며 현재 입력과 비율을 모두 읽을 수 있어야 등록됩니다.
DDC/CI가 지원되어도 비율 제어와 비활성 입력 통신은 모델별 확인이 필요합니다.
입력(0x60)과 비율(0x86)을 DDC/CI로 읽고 쓸 수 있는 모델이 대상입니다.
현재 실기 검증은 AGP346UCSD의 PC=DP / Switch=HDMI 2 조합입니다.
다른 모델은 사용자 등록 프로필로 실제 화면과 입력 전환을 확인해야 합니다.
전용 USB/HID 제어는 구현하지 않았습니다.

Windows 11 x64, .NET Framework 4.8, 모니터 DDC/CI 켜짐이 필요합니다.
PC를 켜두고 영상 케이블 연결을 유지하세요. G-Menu나 USB 연결은 필요하지 않습니다.
비활성 PC 입력에서 DDC 통신이 끊기면 자동 전환이 제한됩니다.
HDMI 선택기 뒤의 여러 기기는 같은 입력으로 보이므로 자동 구분할 수 없습니다.
한 번에 선택한 모니터 한 대를 제어하며, 그 모니터의 여러 입력 기기를 등록합니다.

일반에서 자동 적용, 로그인 시 시작, 확인 간격을 설정합니다.
자동 적용 중에는 수동 OSD 변경이 등록된 비율로 되돌아갈 수 있습니다.
입력을 안정적으로 읽은 뒤 적용하므로 보통 몇 초가 걸립니다.
같은 입력에서 3회 실패하면 멈추며 자동 적용을 껐다 켜거나 입력을 바꾸면 재시도합니다.

설정은 실행 파일 옆 settings.json, 로그는 data/events.log에 저장합니다.
업그레이드 시 종료 후 EXE, EXE.config와 ui-runtime 폴더 전체를 교체하고 기존 settings.json은 보존하세요.
폴더를 이동하면 자동 시작을 껐다가 새 위치에서 다시 켜세요.

소스, GitHub 업로드 및 모델 기여 안내는 저장소 README.md를 참고하세요.

설정 화면은 WinUI 3 다크 모드이며 Windows Mica와 기본 창 버튼을 사용합니다.
투명 효과 설정/절전 상태에 따라 배경 재질은 단색으로 보일 수 있습니다.
ui-runtime 폴더에는 실행에 필요한 .NET 8 및 Windows App SDK가 포함됩니다.

모니터 호환성 → 모니터 등록 해제: 모니터/기기/비율을 제거한 뒤 저장합니다.
일반 → 데이터 관리 → 앱 초기화: 확인 후 설정/백업/로그/진단 파일과 자동 시작을 삭제합니다.
프로그램 파일은 남고 처음 설정 화면이 다시 열립니다. 초기화는 되돌릴 수 없습니다.
